# 贪吃蛇游戏数据字典

## 1. 用户数据 (USER)

| 字段名 | 数据类型 | 长度 | 描述 | 说明 |
|--------|----------|------|------|------|
| id | int | 4字节 | 用户唯一标识符 | 主键，基于时间生成 |
| username | char[] | 50字节 | 用户名 | 用户登录名称 |
| password | char[] | 50字节 | 用户密码 | 用户登录密码 |

## 2. 游戏日志数据 (GAME_LOG)

| 字段名 | 数据类型 | 长度 | 描述 | 说明 |
|--------|----------|------|------|------|
| log_id | int | 4字节 | 日志唯一标识符 | 主键 |
| user_id | int | 4字节 | 用户ID | 外键，关联USER表 |
| username | char[] | 50字节 | 用户名 | 游戏时使用的用户名 |
| start_time | char[] | 30字节 | 游戏开始时间 | 格式：YYYY-MM-DD_HH:MM:SS |
| duration | int | 4字节 | 游戏持续时间 | 单位：秒 |
| score | int | 4字节 | 游戏得分 | 最终得分 |

## 3. 游戏状态数据 (GAME_STATE)

| 字段名 | 数据类型 | 长度 | 描述 | 说明 |
|--------|----------|------|------|------|
| state_id | int | 4字节 | 状态唯一标识符 | 主键 |
| user_id | int | 4字节 | 用户ID | 外键，关联USER表 |
| score | int | 4字节 | 当前得分 | 游戏过程中的即时得分 |
| status | int | 4字节 | 移动方向 | 1:上 2:下 3:左 4:右 |
| sleeptime | int | 4字节 | 移动间隔 | 单位：毫秒 |
| endgamestatus | int | 4字节 | 结束状态 | 1:撞墙 2:咬自己 3:主动退出 |

## 4. 蛇数据结构 (SNAKE)

| 字段名 | 数据类型 | 长度 | 描述 | 说明 |
|--------|----------|------|------|------|
| x | int | 4字节 | X坐标 | 蛇节点的横向位置 |
| y | int | 4字节 | Y坐标 | 蛇节点的纵向位置 |
| next | struct SNAKE* | 8字节 | 下一节点指针 | 指向下一个蛇身体节点 |

## 5. 食物数据结构 (FOOD)

| 字段名 | 数据类型 | 长度 | 描述 | 说明 |
|--------|----------|------|------|------|
| x | int | 4字节 | X坐标 | 食物的横向位置 |
| y | int | 4字节 | Y坐标 | 食物的纵向位置 |

## 6. 游戏日志结构 (LOG)

| 字段名 | 数据类型 | 长度 | 描述 | 说明 |
|--------|----------|------|------|------|
| user_id | int | 4字节 | 用户ID | 外键，关联USER表 |
| username | char[] | 50字节 | 用户名 | 游戏时使用的用户名 |
| start_time | char[] | 30字节 | 游戏开始时间 | 格式：YYYY-MM-DD_HH:MM:SS |
| duration | int | 4字节 | 游戏持续时间 | 单位：秒 |
| score | int | 4字节 | 游戏得分 | 最终得分 |

## 7. 用户数据结构 (USER - 程序内部)

| 字段名 | 数据类型 | 长度 | 描述 | 说明 |
|--------|----------|------|------|------|
| id | int | 4字节 | 用户ID | 用户唯一标识 |
| username | char[] | 50字节 | 用户名 | 用户登录名称 |
| password | char[] | 50字节 | 用户密码 | 用户登录密码 |
